# Voxel World polish: ขนาดและสเกล

อ้างอิงขนาดของ World, structure และ Ambient Life สำหรับ ticket ในโฟลเดอร์นี้
ตัวเลข "ปัจจุบัน" อ่านจากโค้ดบน `feat/voxel-world` (2026-11-11) ส่วนขนาด World วัดซ้ำหลัง ticket 02 (2026-11-12)
ส่วน "ขนาดที่ตัดสินใจแล้ว" คือสเกลใหม่ตาม ADR 0006 ที่จะใช้วาด structure ทั้งหมด

## หน่วย

| หน่วย | ขนาด | ใช้กับ | ที่มา |
|---|---|---|---|
| **cell / unit** | 1 | ช่องบน grid ของ World และ terrain voxel 1 ก้อน | `worldVoxels.ts` |
| **detail voxel** | ¼ unit (`DETAIL = 4`) | ปัจจุบัน: ทุก structure · ต่อไป: สะพาน, บันได, พื้น Dock | ADR 0004, 0006 |
| **structure voxel** | ⅛ unit | ต่อไป: Landmark, Service, ต้นไม้, เรือ, สัตว์, Decoration | ADR 0006 |
| **particle voxel** | ⅛ unit | ใบไม้, ผีเสื้อ, หิ่งห้อย, หิมะ, เถ้า, ฟองคลื่น | ADR 0005, 0006 |
| **interior voxel** | 1/16 unit | House Interior (อีก scene) | ADR 0006 |
| **ความสูงพื้น 1 ขั้น** | 1 unit = 4 detail voxel | ความสูงของ terrain | `terrain.ts` |

แปลงหน่วย: 1 cell = 4×4 detail voxel = 8×8 structure voxel = 16×16 interior voxel

> ตารางขนาด "ปัจจุบัน" ใช้หน่วย detail voxel (¼) ส่วน "ขนาดที่ตัดสินใจแล้ว" ใช้หน่วย ⅛

## ขนาด World

### Island blocks (cell)

**การตั้งค่า** (`terrain.ts`)

- เกาะแต่ละเกาะห่างกัน 4–7 cell

## Structure เทียบกับ World

### Landmark และ vessel ปัจจุบัน

ทุกชิ้นในตารางนี้ใช้ voxel ขนาด **¼ unit** ซึ่งเท่ากับ 4 voxel ต่อ 1 cell ในแต่ละแกน

ความหมายของคอลัมน์
- **footprint (unit)**: ขนาดพื้นที่ที่ตั้ง เป็น unit ของ World
- **โมเดล ก×ล×ส**: ขนาดโมเดล นับเป็นจำนวน ¼ voxel
- **voxel ทั้งหมด**: จำนวน voxel ที่มีสีอยู่จริง นับจากโค้ดโมเดล ไม่นับช่องว่าง
